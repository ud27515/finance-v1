# 家計シミュレーター

GitHub Pagesで公開できる、完全静的な家計シミュレーターです。

## 主な機能
- 我が家データ（現金・投資・収支・将来イベント）の端末内保存
- 住宅ローン繰り上げ返済 vs 運用の比較
- 生活防衛資金・近い将来支出を踏まえた資産配分の可視化
- ChatGPTからのJSON貼り付け
- ChatGPT相談用テキストのコピー
- シミュレーション履歴保存
- JSONバックアップ / 復元
- PWA対応（対応ブラウザではホーム画面追加可）

## データ保存について
データは `localStorage` に保存されます。

- 同じGitHub Pages URL
- 同じブラウザ
- 同じ端末 / 同じブラウザプロファイル

であれば、ページを閉じても記録は残ります。

ただし以下では消える・引き継がれない可能性があります。
- ブラウザのサイトデータを削除した
- シークレット / プライベートモードを使った
- 別の端末・別ブラウザを使った
- GitHub PagesのURLやドメインが変わった

そのため、定期的に「バックアップ」からJSONを書き出してください。

## GitHub Pagesで公開
1. このフォルダの中身をGitHubリポジトリのルートにアップロード
2. GitHubの `Settings` → `Pages`
3. `Deploy from a branch`
4. `main` / `(root)` を選択
5. 表示されたURLを開く

## 注意
本アプリの計算は意思決定支援用の簡易シミュレーションです。税務・住宅ローン控除・金融商品の詳細条件などは個別確認してください。
